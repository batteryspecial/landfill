# landfill

A back-patching bitwise tokenizer and assembler for core RV32I instructions.

## Install

Requires [Rust](https://rustup.rs).

```sh
git clone https://github.com/batteryspecial/landfill.git
cd landfill
./install.sh
```

This installs the `landfill` command to `~/.cargo/bin` and its man page to `~/.cargo/share/man`. Check it worked with:

```sh
landfill --version
man landfill
```
